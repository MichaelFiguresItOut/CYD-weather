CYD Weather Station — UI Mockups (Day & Night)

Four visual directions, each in a day and a night variant — all using the live data from your screenshot (1:03 AM · Sat 14 Nov 2026 · 38.2°F Overcast · feels 32.7°F · no rain).

Resolution note: the glass is natively 240×320 portrait, but per the README your firmware rotates it to landscape — so each screen area is exactly 320 × 240 px, i.e. the same physical pixels as on the device (matching the photo). The dark frame around each screen is just a presentation bezel.

Day/night differences: palette, sky elements (sun ↔ moon/stars), the DAY/NIGHT status chip, and the dog outfit — day uses dogs/very_cold_sun.png (sunglasses), night uses dogs/very_cold.png. All effects are CYD-feasible: flat fills, per-row gradients, rounded rects, bitmap-font text and small sprite animations. No blur or glassmorphism anywhere.
